Customizable buff and consumable tracker for WoW Classic Era. Shows what's missing for your class/spec and lets you click an icon to reapply it.

## Features
- Class-based profiles that pre-select the buffs/consumables relevant to your character
- Clickable tracker icons — click a missing buff/consumable to use/cast it directly
- Movable, lockable tracker frame so it stays out of the way once positioned
- Updates live as buffs are gained/lost, group composition changes, or gear changes
- Follows your Daseeki Core theme and font when Core is installed — chat messages, warning colors, and the HUD countdown numerals all match the rest of the suite
- Your profiles and settings are migrated in place across updates — never wiped by a version change

## Chat Commands
- `/dbt` or `/dbt options` or `/dbt config` — open settings (via the Daseeki hub if Core is installed)
- `/dbt toggle` — show/hide the tracker frame
- `/dbt lock` — lock/unlock the frame so it can't be accidentally dragged
- `/dbt reset` — reset the frame back to its default screen position
- `/dbt auras` — list the buffs currently on you with the exact name and spell ID the game reports for each, and whether Buff Tracker recognises it (paste this if a buff is not being picked up)

## Requires
Optional: Daseeki Core — adds the tracker's options panel to the shared Daseeki options hub and applies the suite theme/font. Works standalone without it.
