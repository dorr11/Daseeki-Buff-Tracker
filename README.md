# Daseeki Buff Tracker

Customizable buff and consumable tracker with class profiles for WoW Classic Era.

## Features

- Tracks buffs and consumables relevant to your class via built-in profiles (`profiles.lua`).
- Clickable icons to apply missing buffs/consumables.
- Configurable tracker frame and display options (`frame.lua`, `options.lua`).

## Requires

- Optional: [Daseeki Core](../Daseeki-Core) — adds the tracker's options panel to the shared Daseeki options hub. Works standalone without it.
